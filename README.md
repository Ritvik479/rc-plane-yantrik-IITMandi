# RC-plane-yantrik-IITMandi

> A fixed-wing RC aircraft designed and built using balsa and depron, developed as part of a team competition project at IIT Mandi.
 
---
 
## 📌 Overview
 
This repository contains all design, simulation, and electronics files for our custom fixed-wing RC plane. The aircraft was designed from scratch — from airfoil selection and aerodynamic analysis to electronics integration and structural layout.
 
---
 
## 📐 Key Specifications
 
| Parameter         | Value               |
|-------------------|---------------------|
| **Configuration** | Fixed-Wing          |
| **Wingspan**      | 1.18 m              |
| **Airfoil**       | ch-10               |

| **Motor**         | BLDC 1400 KV        |

## 🔩 Electronics & Propulsion
 
- **Motor:** Brushless DC (BLDC) 1400 KV outrunner
- **Battery:** 11.1V 3S LiPo
- **ESC:** Compatible with 1400 KV motor (spec accordingly)
- **Receiver/Transmitter:** Standard RC TX/RX system
- **Servos:** Aileron, elevator, and rudder control
 
---
 
## 🧱 Materials
 
- **Balsa wood** — Primary structural material for ribs, spars.
- **Depron foam** — Lightweight sheeting for wing skin and fuselage panels
 
---
 
## 🚀 Getting Started
 
### Viewing CAD Files
Open `.SLDPRT` / `.SLDASM` files using **SolidWorks 2020** or later.
 
### Running Aerodynamic Simulations
- **OpenVSP:** Open the `.vsp3` file from the `Simulation/OpenVSP/` folder using [OpenVSP](http://openvsp.org/).
- **XFLR5:** Load the `.xfl` project file from `Simulation/XFLR5/` using [XFLR5](http://www.xflr5.tech/xflr5.htm).
